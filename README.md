## 概要

**PlayPocket** は、Windows / Android 向けの軽量オフラインプレイリストアプリです。
手元の動画・音楽ファイルをインポートするだけで、広告もアカウント登録も不要なプレイヤーとして、シンプルかつ高速に再生できます。
オンライン環境がなくても、いつでもどこでも自分だけのプレイリストを楽しめます。

## 特徴

### 再生
- ローカルの動画・音声ファイルをドラッグ＆ドロップで追加
- プレイリストの作成・並び替え・管理
- 通常再生 / シャッフル再生の切り替え
- 再生速度の変更、フルスクリーン再生に対応

### 共有・連携
- プレイリストを**共有コード**として書き出し／読み込み可能（他の端末とも共有できます）
- プレイリスト情報のエクスポート
- Discord Rich Presence（再生中の曲をDiscordのステータスに表示）

### カスタマイズ・快適性
- 前回の再生状態を自動的に復元
- 常に最前面に表示 / システムトレイに格納
- Windows起動時の自動起動に対応
- キャッシュ管理・ハードウェアアクセラレーションのON/OFF切り替え

### 環境
- 完全オフラインで動作（インターネット接続不要）
- Windows / Android の両OSに対応
- 軽量・高速でシンプルなUI

## インストール

### Windows

1. 上の **[ダウンロード](https://github.com/Play-Pocket/PlayPocket/releases/latest)** ボタンから最新版をダウンロード
2. `PlayPocket-Installer-1.4.1-Windows.exe` を実行
3. 画面の案内に従ってインストール

> インストール後は、専用インストーラーからアップデート・修復・アンインストールも簡単に行えます。

### Android

1. 上の **[ダウンロード](https://github.com/Play-Pocket/PlayPocket/releases/latest)** ボタンから最新版をダウンロード
2. `PlayPocket-Installer-1.4.1-Android.apk` を実行
3. 画面の案内に従ってインストール

> 提供元不明のアプリのインストールを許可する必要がある場合があります。

---

## 使い方

1. アプリを起動し、動画・音楽ファイルをウィンドウにドラッグ＆ドロップ
2. プレイリストを作成し、好きな順番に並び替え
3. 再生モード（通常 / シャッフル）や再生速度をお好みで設定
4. 作成したプレイリストは共有コードとして書き出し、他の端末に読み込み可能
