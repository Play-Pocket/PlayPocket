      #

      軽量共有コード

      動画を含まない、タイトル・順番・時間だけのコードです。おすすめのリストを渡す用途に向いています。

      設定

      再生

      ネットワークの帯域幅が低いときに自動で音質を調整します。オフにすると、環境によっては再生が途切れることがあります。

      曲の終わりと次の曲の始まりを重ねて、なめらかに切り替えます（追加順・シャッフル再生時）。

      次の曲をあらかじめ読み込み、切り替え時の待ち時間をなくします。

      曲間の無音をできる限りなくし、途切れのない再生を行います。

      すべての曲を分析し、聞こえる音量差が少なくなるように自動調整します。分析結果は端末内に保存され、次回以降は再分析しません。

      左右のスピーカーで同じ音声を再生します。

      表示

      オフにすると映像を表示せず、音声のみを再生します。

      ボタンをアイコン中心の小さな表示にし、画面をより広く使えるようにします。

      システム

      再生中にタスクバーのアプリアイコンにマウスを合わせると、前へ・一時停止・次への操作を表示します（最小化中も有効、Windowsのみ）。

      ハードウェアアクセラレーション、キャッシュ、トレイ、タスクバー設定は必要に応じて再起動後に反映されます。ショートカットは即時切り替えに対応しています。
