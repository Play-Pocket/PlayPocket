## Overview

**PlayPocket** is a lightweight, offline playlist app for Windows and Android.
Just import your local video and music files and enjoy a simple, fast player with no ads and no account required.
Even without an internet connection, you can enjoy your own playlists anytime, anywhere.

## Features

### Playback
- Add local video/audio files by drag & drop
- Create, reorder, and manage playlists
- Switch between normal and shuffle playback
- Adjustable playback speed and fullscreen support

### Sharing & Integration
- Export/import playlists as a **share code** (share with other devices)
- Export playlist information
- Discord Rich Presence (show what you're playing on your Discord status)

### Customization & Comfort
- Automatically restores your last playback state
- Always-on-top mode / minimize to system tray
- Supports launching automatically on Windows startup
- Toggle cache management and hardware acceleration on/off

### Environment
- Works fully offline (no internet connection required)
- Supported on both Windows and Android
- Lightweight, fast, and simple UI

## Installation

### Windows

1. Click the **[Download](https://github.com/Play-Pocket/PlayPocket/releases/latest)** button above to get the latest version
2. Run `PlayPocket-Installer-1.4.2-Windows.exe`
3. Follow the on-screen instructions to install

> After installation, you can also update, repair, or uninstall easily using the dedicated installer.

### Android

1. Click the **[Download](https://github.com/Play-Pocket/PlayPocket/releases/latest)** button above to get the latest version
2. Run `PlayPocket-Installer-1.4.2-Android.apk`
3. Follow the on-screen instructions to install

> You may need to allow installation of apps from unknown sources.

---

## Usage

1. Launch the app and drag & drop your video/music files into the window
2. Create a playlist and reorder tracks as you like
3. Choose your playback mode (normal / shuffle) and playback speed
4. Export your playlist as a share code and import it on another device
